# Excluded historical artifacts

These files are preserved for traceability but are **not canonical** for final comparison:

- `fp16_original.txt`: original FP16 variant result; superseded by the separately tracked FP16 + double-Adam variant.
- `final_metrics_summary.csv`: mixes diagnostic/failed and heterogeneous runs; not the final all-format comparison table.
- `old_partial_double_reference/`: older partial double-reference comparison outputs retained only for audit history.
